# Texniki layihə mətninin yoxlanması

İstifadəçinin tam mətni `tests/fixtures/platform-proposal.json` faylında saxlanılıb. İlkin nəticə dəyişiklikdən əvvəl UI-nin çağırdığı eyni `text-corrector` strategiyası ilə alınıb; aşağıda faktiki əvvəlki və sonrakı çıxışlar var.

## Səbəb və düzəliş

| Problem | Düzəliş |

Əvvəlki 58 test əvvəlki nümunələri əhatə edirdi; bu yeni mətn üçün keyfiyyət zəmanəti deyildi. Yeni testlər tam mətnə dair ayrıca redaktə hədəflərini, müstəqil qısa cümlələri, eyni mətnin təkrar işlənməsinin sabitliyini, xarici terminləri və kodun qorunmasını yoxlayır. Dörd və on iki həftəlik müddətlər, yüz faiz göstəricisi dəyişdirilmir.

Bu redaktor LLM istifadə etmir: lüğət və məhdud kontekst qaydaları ilə işləyir. Bütün sərbəst mətnlərin mənasını insan redaktoru kimi anlaya bilməz. Məsələn, “mənfəət məlumatları” ifadəsinin əslində “məxfi məlumatlar” olub-olmadığını təxmin etmir; texniki və kommersiya iddialarını yoxlamır.

Brauzer yoxlaması Chromium olmadığı və yüklənməsi vaxt aşımına düşdüyü üçün tamamlanmayıb. Aşağıdakı nəticələr tətbiqin istifadə etdiyi strategiyanın faktiki icrasındandır.

## İlkin çıxış

Hörmətli terefdasimiz şirkətimizin proqram təminatı və texnoloji heller korporativ departamenti adından sizi salamlayırıq təqdim etdiyiniz yeni layihənin texniki sertnamesi və biznes telebleri uzmanlarimiz tərəfindən ətraflı şəkildə nəzərdən kecirilmisdir müəyyən olunmus hedefler daxilində sistemin memarligini və istifadəçi tecrubesini ən yüksək seviyyeye qaldırmaq üçün lazımi hazırlıq islerine baslanilmisdir bu məktubda layihənin icra merheleleri funksional modulların strukturu texniki xarakteristikalar və təhlükəsizlik mexanizmləri haqda geniş məlumat təqdim edirik. Məqsədimiz reqabetqabiliyyetli və dayanıqlı bir rəqəmsal məhsul ortaya cixarmaqdir biznes proseslerinizin avtomatlasdirilmasi və fealiyyətinizin rəqəmsal muvite kocurulmesi üçün lazımi olan bütün resurslarimiz səfərbər edilmişdir.

Agile və scrum metodologiyalarina esaslanaraq idarə edilecek olan bu inkişaf prosesi sprintler seklinde bolunmusdur hər bir sprint iki hefdelik müddəti əhatə edəcək və hər sprintin sonunda işlək funksionallıq sınaq mühitində sizə təqdim olunacaqdır bu üsul sayəsində layihedeki dəyişikliklər çevik şəkildə idarə olunacaq və biznes ehtiyaclariniza uyğun olaraq operativ tenzimlemeler aparilacaqdir backlog siyahisindaki tapsiriqlar prioritet sirasina görə duzulmusdur və komandamiz ilk novbede əsas muesse funksiyalarini tamamlamaga diqqət ayiracaqdir sprint qiymətləndirmə görüşləri vasitəsilə inkişaf tempini birgə izləyə bileceyik hər sprintin yekununda həyata keçirilən demo sessiyaları platformanin gidisatini real vaxtda qiymatlendirmeye şərait yaradacaqdır.

Sistemin arxitektura strukturu mikroservis konsepsiyasina esaslanaraq layihelendirilmisdir bu yanaşma hər bir modulun digerinden asılı olmadan murekkeblesmeden genislenmesine imkan yaradır istifadəçi idareetmesi ödəniş inteqrasiyaları bildiriş servisleri və analitika paneli fərqli konteynerlerde fəaliyyət gosterecekdir konteynerlerin orkestrasiyasi kubernetes vasitəsilə həyata keçiriləcəkdir. Bu isə sistemin yuklenmeye uyğun olaraq avtomatik olceklenmesini təmin edəcəkdir nəticədə pikey vaxtlarinda belə sistemin keçiricilik qabiliyyəti və cavab vermə sureti ən üst seviyyede qalacaqdır servislerin bir-birilə əlaqəsi yüksək sürətli grpc protokolu ilə həyata keçiriləcək bu da daxili şəbəkə gecikmelerini minimuma endirecekdir.

Verilənlər bazasinin strukturu yüksək məlumat hacmini desteklemek üçün hisselere bölünmüş və releysnl həm də no sql sistemlerinin birgə istifadəsi esasinda qurulmusdur relasiyali transactional emeliyyatlar üçün PostgreSQL baza sisteminden istifadə olunacaq analitik və böyük veri emalı üçün ise məqsədəuyğun no sql helleri tətbiq ediləcəkdir cəld giriş-çıxış emeliyyatlarini təmin etmək və server yukunu azaltmaq üçün Redis keşleme mexanizmi aktivləşdiriləcəkdir. Məlumatların strukturu duzgundur və gələcəkdə əlavə sahelerin əlavə olunması zəmanət altina alinir baza sorgularinin optimallasdirilmasi üçün xüsusi indeksleme strategiyalari tətbiq olunacaqdır bu da milyonlarla yazinin oldugu cedvellerde belə axtarış suretini millisaniyelere endirecekdir.

API dizayni və sistemlerarasi inteqrasiya mərhələsində rest və öpən API standartlarindan istifadə ediləcəkdir kənar sistemlerle məlumat mubadilesi təhlükəsiz kanallar vasitəsilə həyata keçiriləcək və API keys oauth2 avtorizasiya protokolları tətbiq olunacaqdır sistemdəki emeliyyatlarin gecikmədən emal olunması üçün asinxron mesaj novbeleri aktiv olacaq rabbitmq və ya kafka texnologiyasi vasitəsilə fon tapsiriqlari kəsintisiz icra edileceqdir bu funksionallıq xüsusilə böyük hacmli fayllarin yuklenmesi və kütləvi e-poçt gonderisleri zamanı sistemin donmasinin tamamilə qarşısını alır üçüncü tərəf xidmetlerinin integrasiyasi zamanı avtomatik retry mexanizmləri yaradilacaq və xəta jurnallari müntəzəm arxivlesdirilecekdir.

İstifadəçi interfeysi və təcrübəsi bolmesinde ux ui dizaynerlerimiz istifadəçilərin rahatligini əsas prioritet kimi goturmusdur mobil uyğunluq responsive dizayn prinsipləri ilə təmin olunacaqdır brauzer və cihaz ferqinden asılı olmayaraq platforma eyni keyfiyyetde və suretde fəaliyyət gosterecekdir istifadəçi panelləri sadə aydın və vizual olaraq cəlbedici formada tərtib ediləcəkdir adaptiv komponentler sayəsində səhifələrin yüklənmə sureti optimum seviyyeye getirilecekdir istifadəçi davranislarinin təhlili üçün xüsusi istilik xeriteleri və analitik modullar inteqrasiya olunacaqdır daxili axtarış mühərriki istifadəçilərin axtardigi məlumatları dərhal tapmasina kömək edəcək və dynamic filtrləme imkani təqdim edəcəkdir.

Kibertəhlükəsizlik və data konfidensialligi layihənin ən omemli dayaqlarindan biridir bütün məxfi məlumatlar tls və ssl protokolları ilə sifrelenerek şəbəkə üzərindən oturulecekdir veri bazasinda saxlanılan sifreler və menfeat məlumatları hashing alqoritmləri ilə qorunacaqdir mütəmadi olaraq xoşniyyətli haker sinaglari və penetrasiya testləri həyata keçiriləcək xətalar dərhal aradan qaldirilacaqdir istifadəçi yetkileri rola əsaslanan giriş nəzarəti rbac modeli ilə idarə olunacaqdır bu model səlahiyyətsiz şəxslərin kənar məlumatlara giriş imkanini sifira endirir habelə iki faktorlu doğrulama 2fa sistemi əlavə olunaraq istifadəçi hesablarinin təhlükəsizlik səviyyəsi maksimuma qaldirilacaqdir.

Avtomatlaşdırılmış test prosesləri ci cd boru xetleri vasitəsilə proqram kodunun həyat dovrune inteqrasiya edilmişdir hər bir kod yenilənməsi sınaq serverine yuklenmezden əvvəl avtomatik rəqəmsal unit testler inteqrasiya testləri və e2e testlerden kecirileceyidir bu mexanizm proqram koda daxil edilən xətalarin canlı muhite dusmesinin qarşısına alır və məhsulun keyfiyyət səviyyəsini davamlı olaraq yüksək tutur yeni versiyalarin canlı servere buraxilmasi zamanı zero downtime deployment usullarindan istifadə olunacaqdır kodun deyisdirilmesi zamanı köhnə versiyanin kopyasi ehtiyatda saxlanilacaq və hər hansı bir nasazlıq aninda avtomatik olaraq keçmiş stabil versiyaya qayıdış roll-back təmin olunacaqdır.

Məlumatların kocurulmesi və köhnə sistemlerden yeni platformaya miqrasiyasi xüsusi yazılmış skriptler vasitəsilə həyata keçiriləcəkdir köçürülmə prosesinden əvvəl məlumatların temizlenmesi və strukturlasdirilmasi icra olunacaq duplikasiya olunmus və ya korlanmış yazılar sistemdən cixarilacaqdir miqrasiya sinaqlari əvvəlcədən izolasiya olunmus mühitde dəfələrlə yoxlanılacaq və dəqiqlik faizi yüz faiz olana qədər tənzimlənəcəkdir keçid gecə saatlarında istifadəçi aktivliyinin ən aşağı oldugu zaman kesiyinde icra olunacaqdır bu addım biznesinizin gündəlik emeliyyatlarina heç bir maneə yaratmadan kəsintisiz miqrasiyani təmin etmək üçün nəzərdə tutulmusdur.

Tehsillendirme və adaptasiya mərhələsində şirkətinizin heyetine yeni proqram teminatindan istifadə qaydalari ətraflı izah olunacaqdır inzibatcilar və adii istifadəçilər üçün ayrılıqda onlayn və əyani təlim sessiyaları təşkil ediləcəkdir sistemin istifadə telimatlari video derslikler və addım addım senedlesdirilmis rəhbərlər seklinde təqdim olunacaqdır təlim keçmiş əməkdaşların bilikləri test olunacaq və sualları cavablandirilacaqdir bu yanaşma keçid prosesinin insan amilinden qaynaklanan ləngimələr olmadan rahatlıqla tamamlanmasina imkan yaradacaqdır habelə istifadəçilərin fikirlerini toplamaq üçün xüsusi rəy modulu da yaradilacaqdir.

Layihə tamamlandiqdan sonra sistemin texniki desteyi və monitorinqi yeddi gün yirmi dörd saat esasi ilə davam etdirilecekdir prometheus və grafana kimi idarəetmə vasiteleri ilə serverlerin yuklenmesi yaddaş istifadəsi və şəbəkə trafiki anlıq olaraq izlenilecekdir kritik seviyyede gostericiler artdiqda avtomatik xəbərdarlıq sistemləri texnik heyete bildiriş gonderecekdir bu yanaşma olasi problemleri yaranmadan əvvəl tespit edib qarşısını almağa imkan verir sirketiniz üçün ayrılmış xüsusi menecer istənilən an suallarinizi cavablandirmaga hazır olacaqdır texniki dəstək komandamiz yarana bilecek hər hansı bir sual və ya intensiv sorqu zamanı dərhal müdaxilə etmeye hazırdır.

Maliyyə və resurs planlaması çərçivəsində təklif olunan büdcə və müddət cədvəli layihə sertnamesine tam uyğun olaraq hazirlanmisdir məhsulun ilkin beta versiyasinin dörd hefde ərzində istifadeye verilmesi planlaşdırılır yekun məhsulun tam təhvil verilmesi ise ümumi olaraq on iki hefdelik vaxt çərçivəsində tamamlanacaqdir biz sizinlə uzunmüddətli və uğurlu bir emekdasliga inaniriq və bu layihənin biznesinizə böyük dəyər qatacagina əminlik bildiririk əlavə suallarınız və taklifleriniz üçün bizimlə istədiyiniz an əlaqə saxlaya bilərsiniz. Diqqətiniz üçün təşəkkür edirik. Korporativ dəstəyimiz və proqram təminatı inkişafı komandamiz hər zaman xidmetinizdedir.

## Düzəlişdən sonrakı çıxış

Hörmətli tərəfdaşımız,

Şirkətimizin proqram təminatı və texnoloji həllər korporativ departamenti adından sizi salamlayırıq. Təqdim etdiyiniz yeni layihənin texniki şərtnaməsi və biznes tələbləri mütəxəssislərimiz tərəfindən ətraflı şəkildə nəzərdən keçirilmişdir. Müəyyən olunmuş hədəflər daxilində sistemin memarlığını və istifadəçi təcrübəsini ən yüksək səviyyəyə qaldırmaq üçün lazımi hazırlıq işlərinə başlanılmışdır. Bu məktubda layihənin icra mərhələləri, funksional modulların strukturu, texniki xarakteristikalar və təhlükəsizlik mexanizmləri haqda geniş məlumat təqdim edirik. Məqsədimiz rəqabətqabiliyyətli və dayanıqlı bir rəqəmsal məhsul ortaya çıxarmaqdır. Biznes proseslərinizin avtomatlaşdırılması və fəaliyyətinizin rəqəmsal mühitə köçürülməsi üçün lazımi olan bütün resurslarımız səfərbər edilmişdir.

Agile və scrum metodologiyalarına əsaslanaraq idarə ediləcək olan bu inkişaf prosesi sprintlər şəklində bölünmüşdür. Hər bir sprint iki həftəlik müddəti əhatə edəcək və hər sprintin sonunda işlək funksionallıq sınaq mühitində sizə təqdim olunacaqdır. Bu üsul sayəsində layihədəki dəyişikliklər çevik şəkildə idarə olunacaq və biznes ehtiyaclarınıza uyğun olaraq operativ tənzimləmələr aparılacaqdır. Backlog siyahısındakı tapşırıqlar prioritet sırasına görə düzülmüşdür və komandamız ilk növbədə əsas müəssisə funksiyalarını tamamlamağa diqqət ayıracaqdır. Sprint qiymətləndirmə görüşləri vasitəsilə inkişaf tempini birgə izləyə biləcəyik. Hər sprintin yekununda həyata keçirilən demo sessiyaları platformanın gedişatını real vaxtda qiymətləndirməyə şərait yaradacaqdır.

Sistemin arxitektura strukturu mikroservis konsepsiyasına əsaslanaraq layihələndirilmişdir. Bu yanaşma hər bir modulun digərindən asılı olmadan mürəkkəbləşmədən genişlənməsinə imkan yaradır. İstifadəçi idarəetməsi, ödəniş inteqrasiyaları, bildiriş servisləri və analitika paneli fərqli konteynerlərdə fəaliyyət göstərəcəkdir. Konteynerlərin orkestrasiyası Kubernetes vasitəsilə həyata keçiriləcəkdir. Bu isə sistemin yüklənməyə uyğun olaraq avtomatik ölçəklənməsini təmin edəcəkdir. Nəticədə pik vaxtlarında belə sistemin keçiricilik qabiliyyəti və cavab vermə sürəti ən üst səviyyədə qalacaqdır. Servislərin bir-birilə əlaqəsi yüksək sürətli gRPC protokolu ilə həyata keçiriləcək. Bu da daxili şəbəkə gecikmələrini minimuma endirəcəkdir.

Verilənlər bazasının strukturu yüksək məlumat həcmini dəstəkləmək üçün hissələrə bölünmüş və həm relational, həm də NoSQL sistemlərinin birgə istifadəsi əsasında qurulmuşdur. Relyasiyalı transactional əməliyyatlar üçün PostgreSQL baza sistemindən istifadə olunacaq. Analitik və böyük veri emalı üçün isə məqsədəuyğun NoSQL həlləri tətbiq ediləcəkdir. Cəld giriş-çıxış əməliyyatlarını təmin etmək və server yükünü azaltmaq üçün Redis keşləmə mexanizmi aktivləşdiriləcəkdir. Məlumatların strukturu düzgündür və gələcəkdə əlavə sahələrin əlavə olunması zəmanət altına alınır. Baza sorğularının optimallaşdırılması üçün xüsusi indeksləmə strategiyaları tətbiq olunacaqdır. Bu da milyonlarla yazının olduğu cədvəllərdə belə axtarış sürətini millisaniyələrə endirəcəkdir.

API dizaynı və sistemlərarası inteqrasiya mərhələsində REST və OpenAPI standartlarından istifadə ediləcəkdir. Kənar sistemlərlə məlumat mübadiləsi təhlükəsiz kanallar vasitəsilə həyata keçiriləcək və API keys və OAuth2 avtorizasiya protokolları tətbiq olunacaqdır. Sistemdəki əməliyyatların gecikmədən emal olunması üçün asinxron mesaj növbələri aktiv olacaq. RabbitMQ və ya Kafka texnologiyası vasitəsilə fon tapşırıqları kəsintisiz icra ediləcəkdir. Bu funksionallıq xüsusilə böyük həcmli faylların yüklənməsi və kütləvi e-poçt göndərişləri zamanı sistemin donmasının tamamilə qarşısını alır. Üçüncü tərəf xidmətlərinin inteqrasiyası zamanı avtomatik retry mexanizmləri yaradılacaq və xəta jurnalları müntəzəm arxivləşdiriləcəkdir.

İstifadəçi interfeysi və təcrübəsi bölməsində UX/UI dizaynerlərimiz istifadəçilərin rahatlığını əsas prioritet kimi götürmüşdür. Mobil uyğunluq responsive dizayn prinsipləri ilə təmin olunacaqdır. Brauzer və cihaz fərqindən asılı olmayaraq platforma eyni keyfiyyətdə və sürətdə fəaliyyət göstərəcəkdir. İstifadəçi panelləri sadə, aydın və vizual olaraq cəlbedici formada tərtib ediləcəkdir. Adaptiv komponentlər sayəsində səhifələrin yüklənmə sürəti optimum səviyyəyə gətiriləcəkdir. İstifadəçi davranışlarının təhlili üçün xüsusi istilik xəritələri və analitik modullar inteqrasiya olunacaqdır. Daxili axtarış mühərriki istifadəçilərin axtardığı məlumatları dərhal tapmasına kömək edəcək və dynamic filtrləmə imkanı təqdim edəcəkdir.

Kibertəhlükəsizlik və data konfidensiallığı layihənin ən önəmli dayaqlarından biridir. Bütün məxfi məlumatlar TLS və SSL protokolları ilə şifrələnərək şəbəkə üzərindən ötürüləcəkdir. Veri bazasında saxlanılan şifrələr və mənfəət məlumatları hashing alqoritmləri ilə qorunacaqdır. Mütəmadi olaraq xoşniyyətli haker sınaqları və penetrasiya testləri həyata keçiriləcək. Xətalar dərhal aradan qaldırılacaqdır. İstifadəçi yetkiləri rola əsaslanan giriş nəzarəti RBAC modeli ilə idarə olunacaqdır. Bu model səlahiyyətsiz şəxslərin kənar məlumatlara giriş imkanını sıfıra endirir. Habelə iki faktorlu doğrulama 2FA sistemi əlavə olunaraq istifadəçi hesablarının təhlükəsizlik səviyyəsi maksimuma qaldırılacaqdır.

Avtomatlaşdırılmış test prosesləri CI/CD boru xətləri vasitəsilə proqram kodunun həyat dövrünə inteqrasiya edilmişdir. Hər bir kod yenilənməsi sınaq serverinə yüklənməzdən əvvəl avtomatik rəqəmsal unit testlər, inteqrasiya testləri və e2e testlərdən keçiriləcəkdir. Bu mexanizm proqram koduna daxil edilən xətaların canlı mühitə düşməsinin qarşısını alır və məhsulun keyfiyyət səviyyəsini davamlı olaraq yüksək tutur. Yeni versiyaların canlı serverə buraxılması zamanı zero downtime deployment üsullarından istifadə olunacaqdır. Kodun dəyişdirilməsi zamanı köhnə versiyanın kopiyası ehtiyatda saxlanılacaq və hər hansı bir nasazlıq anında avtomatik olaraq keçmiş stabil versiyaya qayıdış roll-back təmin olunacaqdır.

Məlumatların köçürülməsi və köhnə sistemlərdən yeni platformaya miqrasiyası xüsusi yazılmış skriptlər vasitəsilə həyata keçiriləcəkdir. Köçürülmə prosesindən əvvəl məlumatların təmizlənməsi və strukturlaşdırılması icra olunacaq. Duplikasiya olunmuş və ya korlanmış yazılar sistemdən çıxarılacaqdır. Miqrasiya sınaqları əvvəlcədən izolasiya olunmuş mühitdə dəfələrlə yoxlanılacaq və dəqiqlik faizi yüz faiz olana qədər tənzimlənəcəkdir. Keçid gecə saatlarında istifadəçi aktivliyinin ən aşağı olduğu zaman kəsiyində icra olunacaqdır. Bu addım biznesinizin gündəlik əməliyyatlarına heç bir maneə yaratmadan kəsintisiz miqrasiyanı təmin etmək üçün nəzərdə tutulmuşdur.

Təlimləndirmə və adaptasiya mərhələsində şirkətinizin heyətinə yeni proqram təminatından istifadə qaydaları ətraflı izah olunacaqdır. İnzibatçılar və adi istifadəçilər üçün ayrılıqda onlayn və əyani təlim sessiyaları təşkil ediləcəkdir. Sistemin istifadə təlimatları video dərsliklər və addım-addım sənədləşdirilmiş rəhbərlər şəklində təqdim olunacaqdır. Təlim keçmiş əməkdaşların bilikləri test olunacaq və sualları cavablandırılacaqdır. Bu yanaşma keçid prosesinin insan amilindən qaynaklanan ləngimələr olmadan rahatlıqla tamamlanmasına imkan yaradacaqdır. Habelə istifadəçilərin fikirlərini toplamaq üçün xüsusi rəy modulu da yaradılacaqdır.

Layihə tamamlandıqdan sonra sistemin texniki dəstəyi və monitorinqi yeddi gün, iyirmi dörd saat əsasında davam etdiriləcəkdir. Prometheus və Grafana kimi idarəetmə vasitələri ilə serverlərin yüklənməsi, yaddaş istifadəsi və şəbəkə trafiki anlıq olaraq izləniləcəkdir. Kritik səviyyədə göstəricilər artdıqda avtomatik xəbərdarlıq sistemləri texnik heyətə bildiriş göndərəcəkdir. Bu yanaşma ehtimal olunan problemləri yaranmadan əvvəl müəyyən edib qarşısını almağa imkan verir. Şirkətiniz üçün ayrılmış xüsusi menecer istənilən an suallarınızı cavablandırmağa hazır olacaqdır. Texniki dəstək komandamız yarana biləcək hər hansı bir sual və ya intensiv sorğu zamanı dərhal müdaxilə etməyə hazırdır.

Maliyyə və resurs planlaması çərçivəsində təklif olunan büdcə və müddət cədvəli layihə şərtnaməsinə tam uyğun olaraq hazırlanmışdır. Məhsulun ilkin beta versiyasının dörd həftə ərzində istifadəyə verilməsi planlaşdırılır. Yekun məhsulun tam təhvil verilməsi isə ümumi olaraq on iki həftəlik vaxt çərçivəsində tamamlanacaqdır. Biz sizinlə uzunmüddətli və uğurlu bir əməkdaşlığa inanırıq və bu layihənin biznesinizə böyük dəyər qatacağına əminlik bildiririk. Əlavə suallarınız və təklifləriniz üçün bizimlə istədiyiniz an əlaqə saxlaya bilərsiniz. Diqqətiniz üçün təşəkkür edirik. Korporativ dəstəyimiz və proqram təminatı inkişafı komandamız hər zaman xidmətinizdədir.
