# testt.txt nümunəsinin yeni nəticəsi

Aşağıdakı mətn yenilənmiş redaktorun faktiki çıxışıdır. Girişdəki `bu input du` və əvvəlki çıxış ayrıca ayrılıb, yalnız orijinal mətn emal edilib. Cümlə sərhədləri, vaxt keçidlərinə görə abzaslar, diakritikalar və texniki adların məlum səhvləri düzəldilib; bu nəticə tam semantik və üslubi redaktə zəmanəti deyil.

Salam, bu gün səhər saat səkkizdə oyandım. Təcili geyinib çölə çıxdım, çünki işdə vacib görüş var idi, amma tıxaca düşdüm. Avtobus çox dolu idi. Hamı bir-birini itələyirdi. Bir təhər işə çatdım. Müdir mənə qəzəblə baxdı. Dedi ki, niyə gecikmisən? Layihə təhvil verilməlidir. Serverdə problem var. Bazaya sorğular getmir. Mən də keçdim kompüterin arxasına. Ubuntu sistemində terminalı açıb loglara baxdım. Gördüm ki, sonsuz bir loop düşüb bazanı doldurur. Həmin o prosesi kill elədim. FastAPI servisini yenidən başlatdım. Hamısı qaydasına düşdü. Müdir rahat nəfəs aldı. Dedi: bir də gecikmə. Mən də keçdim yerimə oturdum.

Günorta uşaqlarla aşağı kafeyə endik. Dönər sifariş verdik, amma əti pis idi. Heç yeyə bilmədim. Kolanı içib yuxarı qalxdım.

Günün ikinci yarısı yeni müştəri gəldi. Dedi ki, veb səhifə lazımdır. SRS sənədini hazırlayırdım. Müştəri nə istədiyini bilmir. Sistem analitiki kimi gərək hamısını strukturlaşdırım.

Axşam saat altı oldu. İdman zalına getdim. Kardio elədim. Qaçış zolağında yarım saat qaçdım. Təqribən dörd yüz kalori yandırdım. Creatin qəbul etməyi unutmuşdum deyə enerjim az idi. Zalda idman ayaqqabısı haqqında danışdıq. Nike Air Max və Jordan Stadium modellərini müqayisə elədik.

İdmandan çıxıb marketə girdim. Çörək, süd aldım. Kassada növbə var idi. Kassa aparatı xarab olmuşdu. Nağd pul verib çıxdım.

Evə çatanda saat doqquz idi. Anama zəng elədim. Dedim: hər şey yaxşıdır.

Evə girib yemək qızdırdım. Sonra kompüteri açdım. Resume parser layihəsi var idi. PDF CV məlumatlarını JSON formatına salırdı. LLM modelinə sorğu göndərəndə bəzən düzgün cavab qaytarmırdı. Promptu tənzimlədim. Pydantic validator yazdım ki, outputu təmizləsin.

Gecə saat on birdə dostum zəng elədi. Chess.com-da şahmat oynadıq. Birinci oyunda vəziri itirdim. İkincidə mat elədim. Sonra Linuxda köhnə oyunları işlətmək haqqında video izlədim. Pəncərəni açdım. Havanı içəri buraxdım. Yatağa uzandım. Gözlərimi yumdum. Sabaha olan planları düşündüm.

Sabah səhər təzədən eyni şeylər başlayacaqdı. Təzə sprint planning var idi. Story pointləri təyin etmək lazım idi və yuxuya getdim.
