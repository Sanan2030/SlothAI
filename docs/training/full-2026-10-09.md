the container has a **4-core quota**, **32 GiB memory ceiling** and no usable GPU.
Measured smoke extrapolations suggest around **57 hours CharSpell** and **12 hours

The supervisor monitors both mounts, stops its verified process group if workspace
free space falls below **2 GiB** or temporary free space below **1 GiB**, and
preserves partial outputs. Temporary gate/SQLite work uses `/tmp`. It refuses
existing model outputs, stale/recycled process identities, changed preparation
receipts, configuration or semantic training source. A zero process exit must
also have a completed report with matching prepared-data/model hashes.

Neural jobs retain last completed-epoch optimizer checkpoints. After interruption,
inspect live processes and reports before using the existing trainer's guarded
`--resume`; partially executed epochs repeat from the last checkpoint. WordLM
cannot resume, and interrupted preparation needs a new output directory. The
supervisor does not blindly relaunch or overwrite a prior job. CPU/RSS records
distinguish cumulative maximum waited-child RSS from a stage or host memory peak.
