# CharSpell application integration, 6 November 2026

Both text and mail now load the completed CharSpell character CNN automatically. It scores the same bounded candidate pool as WordLM; its original float32 logits join the existing language and edit-channel scores. No activation control or external inference service is introduced. Each response and browser-local transform log includes a `charSpell` receipt with checkpoint hash, parameter count, ranked positions, candidate count and model-supported accepted changes.

The full CPU run finished on 5 November at 22:29 Baku time: four completed epochs, with epoch two selected by the lowest validation mean loss. Epochs three and four worsened, so patience two stopped training. The application retains all 21,857 original learned parameters from checkpoint SHA256 `7d4338fc926023491d2d2f2c46196f7eb39af8bfad9134793e7ce596ba7e8ae3`. There is no new weight fitting or quantization. Training's source-split validation rates are synthetic and conditional on target retrieval; they are not real-user correction accuracy.

`training/export_charspell.py` requires a completed, hash-matching accepted full run and matching checkpoint/configuration. `lib/editor/charspell/load.ts` checks the decoded payload size and SHA256 before constructing the scorer. The implementation preserves the embedding table, both convolution kernels, masked max pooling, projection and exact five-part scoring feature order. Empty contexts, padding, unknown characters, long words and left-context cropping are covered. Caches are bounded and usage counters are request-local.

PyTorch and an actual Chromium Worker were compared on 56 deterministic numerical examples / 202 candidate logits. The maximum absolute difference is 0.0000152587890625, below the 0.001 tolerance. These fixtures test numerical implementation, not linguistic quality or policy selection. Original float32 is small enough that int8 conversion is unnecessary here.

The policy uses engineering weight one and character evidence margins four/eight; these are relative scores, not calibrated probabilities. The reserved authored calibration set remains 100/100 with no new failures. Its four repeated frames across 25 domains do not establish representative real-error calibration. No validation/test/QA sentences were used to fit these neural weights.

Character-only disagreement cannot overwrite an attested preceding meaning without empirical context. Decisive retained corpus evidence and verified lexical/context decisions keep their authority. Classifier features are supplemented with bounded, reviewed word-family and grammatical relations; correct-word, proper-name, technical-term and literal protection remain part of selection. The improvement is a hybrid pipeline result, not isolated causal accuracy of CharSpell.
