# Redaktor jurnalı

Tətbiq hər düzəlişin girişini və nəticəsini yalnız həmin brauzerin `localStorage` yaddaşında saxlayır. Son 50 qeyd saxlanılır; saxlanma bloklanarsa istifadəçiyə xəbərdarlıq göstərilir. `Günlüyü yüklə` düyməsi JSON faylı kompüterə endirir. Brauzer yaddaşı silinərsə jurnalı bərpa etmək olmur.

Jurnalı burada təhlil etmək üçün yüklənən JSON faylını söhbətə əlavə edin və ya öz kompüterinizdə bu `logs/` qovluğuna köçürün. `logs/*.json` Git tərəfindən nəzərə alınmır; mətnlər avtomatik repoya və Vercel-ə ötürülmür. Paylaşmazdan əvvəl şəxsi məlumatları yoxlayın.
